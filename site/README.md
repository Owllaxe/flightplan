# Flightplan — site

Static build of **Page 4** of the Figma file
[Stellic FrontEnd Design](https://www.figma.com/design/Bg342a4k8osKHaxsL09w5q/Stellic-FrontEnd-Design?node-id=388-55).
Plain HTML, CSS and ES modules — no build step and no dependencies.

## Run

```bash
python site/tools/serve.py 5173
```

Then open <http://localhost:5173>. (There is also a `site` entry in `.claude/launch.json`.)
`serve.py` is a plain static server that adds `Cache-Control: no-store`, so an
edited page never comes back from the browser cache. `python -m http.server`
works too, but leaves you hard-refreshing after every change.

## Layout

```
site/
  *.html          one file per screen
  css/
    base.css      design tokens, app shell, sidebar, shared primitives
    schedule.css  the week grid, shared by Home and Profile
    career.css  home.css  profile.css  resume.css  plan.css  goals.css
    planner.css  visa.css  login.css
  js/
    store.js      localStorage-backed state, one JSON blob under `stellic-pathfinders`
    app.js        shared behaviour: bookmarks, checkboxes, text fields, banners, modals
    career.js  home.js  profile.js  resume.js  plan.js  goals.js
  assets/         PNGs and SVGs exported from the Figma frames
```

Anything marked `data-bookmark`, `data-check` or `data-field` persists to
localStorage automatically and is shared across screens — the goals ticked on Home
are the same records the Career Plan board edits.

## Two deliberate departures from the file

- **Sidebar.** Each frame was drawn with a different sidebar (`Oliver Gan` /
  `Name of Site` / `Study Maxing`, and 140/165/170/217px widths, with different nav
  items). Every page now uses one canonical sidebar instead, taken from the most
  complete frame — Home `388:1275`: 217px wide and six nav items
  (Home / Planner / Goals / Career / Contacts / Visa). It lives entirely in
  `css/base.css`; no page overrides it. The footer avatar is the link to
  `profile.html`. The brand lockup (rock + `Flightplan` + `DEGREE + CAREER`), the
  `THIS TERM` block under the nav and the initials-circle avatars come from build
  B — see `tools/buildB-spec.md` §3.2, §3.4 and §6. `js/sidebar.js` paints the
  `THIS TERM` numbers and the initials from `js/store.js` (`term` / `identity`).
- **Headline font.** The real `Pathfinder Hand` face was recovered from build B
  and is now self-hosted from `assets/b/PathfinderHand.woff2` (`@font-face` in
  `css/base.css`, `font-display: swap`). `--font-hand` keeps its stack —
  `'Pathfinder Hand', 'Patrick Hand', 'Caveat', cursive` — with the two
  substitutes behind it as fallbacks. **The face ships one weight only**, so any
  `font-weight: 600`/`700` on it is synthesised by the browser. Body text (Inter),
  card titles (Playfair Display), nav (Caveat) and the board cards (Playpen Sans)
  are the fonts the file specifies, loaded from Google Fonts; `css/base.css` also
  `@import`s JetBrains Mono and Newsreader for build B's micro-labels and initials
  circles. Redistribution of `Pathfinder Hand` is a licensing question that has
  not been answered — check it before shipping publicly.
